# Single-issue execution card template

**Ticket:** e.g. SYS-01  
**Status:** READ_ONLY_INSPECTION (default)  
**Target:** `page → component → element` from issue register  
**Evidence:** original screenshot + focus crop (if available)

## 1. Reproduction
- Build/version/device/viewport/theme: UNKNOWN until tested.
- UI path/scroll state/tap action: ...
- Observation vs expected user task: ...
- Screenshot comparison with baseline: ...

## 2. Source discovery (read only)
- Exact route/component/source path + line location: ...
- Shared consumer list: ...
- CSS/layout/z-index/state sources: ...
- Root cause: VERIFIED / INFERRED / UNKNOWN, with supporting code.

## 3. Fix proposal, before permission
- Smallest systemic change that solves all consumers: ...
- Preserved behavior/visual identity: ...
- Risk to state, security, data, accessibility: ...
- Alternatives and decision boundary: ...
- Approval requested/received: ...

## 4. After authorized implementation
- Changed files and why: ...
- Tests run / exact output: ...
- QA test ID / PASS, FAIL, NOT_RUN / artifacts: ...
- Before & after at matched state: ...
- Other routes checked: ...
- Rollback: ...

## 5. Acceptance
Only close when evidence demonstrates the actual issue is resolved at all affected pages without loss of feature, and no tests are claimed PASSED unless executed.
