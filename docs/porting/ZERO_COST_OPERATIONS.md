## Free-tier guard
The optional Turso reader uses the official HTTP pipeline (https://docs.turso.tech/sdk/http/reference), bounded SQL with parameter bindings, a read-only scoped token, immutable snapshot hash check, 2.5s timeout, maximum 2 MiB response, strict 30-minute Redis cache, and shared 1,000 cache-miss admissions/UTC day. On Redis ledger failure or exhausted cap, optional remote catalogue work stops. This cap is a conservative application setting, NOT a guarantee of provider billing consumption. It doesn't meter CDN traffic, platform CPU, Redis commands from other features, or Firebase reads/writes. Official dashboards remain authoritative. Check at 80% and restrict optional operations before provider caps; if account billing is not verified free, do not activate. Vercel Hobby may stop serving on reaching limits, not auto-buy more (https://vercel.com/docs/plans/hobby). No new cron on Vercel.
